# 此刻 MOMENT · 个人日程管理 v1.0.1

「此刻 MOMENT」是一款本地优先、数据自持、常驻托盘的桌面日程管理软件。回答「此刻该做什么」：事件 / 日常 / 浮动事项三类数据 + 五层候选推荐引擎 + 今日时间轴 + 系统级提醒。

当前版本 **1.0.1**，数据版本 `CURRENT_VERSION = 4`。

## 功能全景

- **「现在」页**：大时钟（按配置时区）+ 主候选/次选 + 今日时间轴 + 应用内提醒横幅；
- **日历**：月/周/日视图，重复事件实例展开、日常窗口叠加、显示内容与标签筛选（标签颜色着色）；
- **事件 / 日常 / 浮动事项**：列表、行内编辑（失焦自动保存）、右侧 480px 抽屉（显式「取消 / 保存」）；
- **搜索 / 归档 / 统计复盘**：全文与标签筛选、手动补记（按浏览日期归入正确天）、标签耗时与日常完成率；
- **自然语言快速录入**：如「明天下午3点开会」，解析失败自动降级表单；
- **重复事件**：daily/weekly/monthly/yearly/custom + 多级提前提醒 + 「完成仅归档本次」；
- **系统提醒**：事件开始/多级提前、日常窗口开始/即将结束、浮动事项截止；优先级分级（高/中/低 → 系统/仅应用内/不提醒）+ 免打扰时段 + 提示音开关；
- **计时器**：单计时器开始/暂停/继续，实际耗时写入归档与统计；
- **跳过 / 稍后 / 撤回**：稍后跨零点不丢失，到点自动重新提醒；
- **标签颜色**：设置页为标签选择 10 色浅/深主题色板，标签芯片、过滤条、日历事项同步着色；
- **数据目录 / 导入导出**：自定义目录、JSON 导出导入；
- **事项模板**：工作日 / 周末 / 自定义模板批量生成；
- **脚本钩子**：受限 JS（boa）导出钩子，执行限时 2 秒 + 循环/递归限制；
- **托盘 / 全局快捷键 / 主题**：最小化到托盘、快捷键唤起、浅色/深色/跟随系统；
- **开机自启动**：设置页一键开关，写入当前用户 Windows 启动项；
- **单实例保护**：重复点击 exe 时唤起已有主窗口，不会开启第二个应用；
- **数据安全红线**：本地 JSON 原子写入 + `.bak` + 软删除 + 时区归一化 + mtime 外部修改冲突（重载 / 覆盖二选一）。

> 说明：Git 一键备份与移动端只读功能已按用户要求完全移除（后端模块/命令/状态与前端入口均已删除）。

## 技术栈

- 桌面壳：Tauri 2.x（Rust 后端）
- 前端：React 18 + TypeScript 5 + Vite 5 + Tailwind CSS 3 + Zustand 4
- 存储：本地 JSON（原子写入 + `.bak` 备份 + 版本迁移 v0→v4 + mtime 外部修改检测 + 软删除）
- 核心：`schedule-core` 纯 Rust crate（模型 / 存储 / 候选引擎 / 重复展开 / NLP / 搜索 / 统计 / 钩子）

## 运行与构建

```powershell
npm install
npm run tauri dev      # 开发模式
npm run tauri build    # 发布构建（需 Visual Studio Build Tools + Rust MSVC 工具链）
```

构建验证命令：

```powershell
npx tsc --noEmit
npm run build
cargo test -p schedule-core
cargo check -p schedule-app
npm run tauri build
```

> 路径含中文时请使用 MSVC 工具链；MSI 打包已配置 WiX `zh-CN` 代码页。

## 数据目录

- 默认：Tauri `app_data_dir`（Windows 下为 `%APPDATA%\com.personal.schedule` 一类路径）。
- 自定义：设置页「数据目录」选择后写入默认目录下的 `data_dir.txt` 指针文件。
- 文件结构：`config.json`、`events.json`、`routines.json`、`tasks.json`、`templates.json`、`archive/YYYY-MM.json`、`hooks/`；每份数据文件均含 `version` 字段，损坏时自动备份 `.corrupt-*.bak`，覆盖前复制 `.bak`。
- 严禁多端同时读写同一数据目录（网盘/Git 同步场景）；应用检测到外部修改会弹「重新加载 / 覆盖」选择，不再静默覆盖。

## 安全提示

- 移动端只读：仅限局域网，切勿端口映射公网/内网穿透；密码经 HTTP 明文传输。
- 脚本钩子：默认关闭，启用后执行 `hooks/*.js`（受限解释器，限时 2 秒），仅放信任脚本。
- Git/网盘：禁止多端同时读写同一数据目录。
