# 用户体验反馈

> 体验版本 v2.0（应用版本 0.4.0）

## 日历功能

希望可以更详细的设置日历的显示内容，包括只显示事件，只显示日常，或者都显示等等。以及可以根据标签等进行筛选显示。

## 标签功能

在设置标签时，希望能提示已有标签类型，并能直接选择。或者定义新标签。

## 现在

在现在页面中，点击对应任务开始后，只提示了一个开始的信息，我建议应该在事项中开启一个计时器，可以显示在事项的右侧，用来显示该事项的实际进行时间,而在统计中，记录实际进行时间，同时开始按键变成暂停按键。

日常点击完成后，若仍在该时间段内，则事项仍然存在，且可再次点击完成，导致时间轴上会多次归档。

跳过和稍后没有撤回功能，同时功能不完善，跳过要有二次确认，防止误触。稍后则需要指定延后的时间，待延后时间到时再显示。

## 扩展

启用功能选择（包括启用自动备份，启用移动端只读）等都会卡死，但重启后生效。

移动端只读，访问地址建议直接显示可访问的地址，而不是用 “本机局域网IP” 代替

访问地址后http://<本机局域网IP>:8731 后，页面空白无内容

## 其他

深色主题，文本框颜色与其中文字颜色接近看不起文字内容。

提醒功能并没有系统级的提醒，在软件外没有收到提醒信息。只是在现在界面有提醒信息。

提醒功能要分级提醒，例如对于高优先级的事件要在开始前系统级提醒，而中低优先级的内容仅在现在界面显示提醒即可。（具体提醒分级可以设置）

数据目录增加一个打开当前数据目录的选项。
