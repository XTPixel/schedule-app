- `npm run build`：通过，TypeScript 与前端生产资源构建成功。
- `cargo test --manifest-path src-tauri/Cargo.toml -p schedule-core -p schedule-app --lib --offline`：核心 41、应用 27，共 68 项通过。
- `.tools/android-smoke.cjs`：10 项通过，运行在真实安装的调试 APK 上，经 WebView 调试接口调用 Rust IPC；包含自然语言半点、事件/浮动事项保存、长期任务有效投入与幂等、搜索、统计、移动导航、计时后台恢复、离线只读与断开、杀进程后数据持久化。
- 原生 SAF 文档导出、删除隔离 QA 事项后再导入恢复：通过；导出 JSON 验证不含测试凭据及口令。
- 系统通知运行时权限：允许成功；应用退至桌面后，预排系统闹钟送达通知；完成事项后对应系统闹钟已取消。插件不登记 `show` 方式的闹钟，已改用应用自己的登记记录管理取消。
- 本地恢复点：原生导入后恢复导入前的 QA 事项，且恢复前的当前副本也被保留，通过。
- Android 安全区域：状态栏与导航栏正常显示；软键盘弹出时 WebView 高度由 582 缩至 307 CSS px，输入框保持可见。
- 测试只操作独立模拟器中的 QA 数据和虚构凭据，没有连接真实云空间或修改用户业务数据。

## 环境问题与处理

软件渲染的两个模拟器版本均在 Android 启动前原生崩溃。经用户明确同意安装 Google Android Emulator Hypervisor Driver，用户确认管理员提示，AEHD 2.2 安装成功；随后 Android 15 正常启动。未重启 Windows。

所有项目新增构建产物与临时目录在 D 盘。`D:\moment-build` 指向项目 `.build-cache`；原生 Rust 编译使用物理 ASCII 路径 `D:\moment-native-build`，避免 NDK 解析中文目录失败。SDK/JDK 原有 C 盘安装仅作为已安装工具读取。两种架构分别打包，已禁用开发构建 Rust 调试信息；正式 Release 体积尚待记录。
