## 三、数据迁移（v2 → v3）

- `CURRENT_VERSION = 3`；事件/日常/浮动/归档/templates 结构**零改动**。
- 仅 `config.json` 的 `notifications` 补齐（`migrate_v2_to_v3`）：

```jsonc
"notifications": {
  // 保留 enabled / sound / doNotDisturb
  "priorityPolicy": { "high": "system", "normal": "app", "low": "app" }
}
```

- 计时器、跳过/稍后走前端 `localStorage`（按天 key 隔离），不落数据文件，无需迁移。
- 兼容保证：serde 忽略未知字段（前向）；`version` 高于当前版本拒绝加载；原子写入/`.bak`/mtime/软删除/时区策略不变。

## 四、关键业务语义

1. **B1**：`set_config` 先落盘并立即返回；`register_hotkey`/`restart_mobile`/`restart_git_autocommit` 移入后台线程；`MobileServer::stop` 仅 `unblock()` 不再同步 `join`。
2. **B5（三层防护）**：候选引擎层级 2 过滤 `done_today`；`persist_archive` 对非手动来源按 `(source, sourceId)` 当日幂等去重；`complete_candidate` 对 Routine 不写完成标记（依赖归档 `done_today`）。
3. **F1 单计时器**：开始新事项自动暂停上一个；`durationMinutes = max(1, round(elapsedMs/60000))`，经 `durationMinutesOverride` 写入归档 `durationMinutes`，统计自动反映。
4. **F2**：`skipped`（当日跳过）与 `snoozed`（稍后至某时刻）按天 key 持久化；`hiddenCandidates = skipped ∪ snoozed(未到期)`；跨天自动清理。
5. **F5**：后台 30s 线程调用 `check_and_notify`，复用 `notified` 去重；`should_notify = 全局开关 && !免打扰 && policy(priority)=="system"`。

## 六、用户侧提示

- **Git/网盘**：禁止多端同时读写同一数据目录（脑裂覆盖）。
- **脚本钩子**：默认关闭；启用后执行 `hooks/*.js`，仅放信任脚本。
- **移动端只读**：仅局域网，切勿映射公网/内网穿透；密码 HTTP 明文传输。
- **分级提醒**：默认高优先级系统级、中/低仅应用内，可在设置页调整。
