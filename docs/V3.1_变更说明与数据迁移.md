## 三、数据迁移（v3 → v4）

- `CURRENT_VERSION = 4`；事件/日常/浮动/归档/templates 结构**零改动**。
- 仅 `config.json` 补齐（`migrate_v3_to_v4`）：

```jsonc
"tagColors": {}
```

- 旧 v0/v1/v2/v3 数据经既有迁移链 `v0→v1→v2→v3→v4` 自动升级且无损。
- serde 对未知字段继续忽略（前向兼容）；高于当前版本拒绝加载；原子写入、`.bak`、软删除、时区策略不变。
- 稍后/跳过/计时器仍走前端 `localStorage`，不落数据文件；其中稍后集合升级为单一 key（旧按天 key 数据在升级后自然过期，无需迁移）。

## 四、关键业务语义

1. **T2 提醒去重**：`event_start:{occ.key}`、`event_reminder:{occ.key}:{offset}`、`routine_window:{rt.id}:{w.start}:start` / `...:{w.end}:end`、`task_deadline:{t.id}:{date}`；`notified` 跨天清空，30s 轮询不重复。
2. **T3 外部修改**：后端在写入前比较磁盘 mtime 与读取基线，不一致且未选覆盖时返回 `EXTERNAL_CHANGE:<file>`；前端弹「覆盖外部改动 / 重新加载（放弃本地修改）」；`overwrite` 只放开下一次写，成功后自动复位。
3. **T4 配置收敛**：`set_config` 不再派生任意多个线程；applier 每 100ms 比较 generation，按最新 config 串行应用配置（当前仅全局快捷键；移动端/Git 重启逻辑已随功能移除）。
4. **U5 抽屉**：`updateDraft` 仅改本地草稿；保存校验标题非空；新建草稿保存前无任何持久化副作用；保存失败留在抽屉。
5. **U4 标签颜色**：`tagColors` 键为标签名、值为 token（red/orange/amber/green/teal/blue/indigo/violet/pink/gray）；未设置回退默认灰；重命名/删除标签后端原子迁移映射。

## 六、功能移除记录（后续用户要求）

**Git 一键备份与移动端只读已完全移除**：

- 后端：删除 `src-tauri/src/git_backup.rs`、`src-tauri/src/mobile.rs`；删除 Git 状态/备份/最近错误、移动端状态、防火墙规则、局域网地址等全部命令；移除 `tiny_http` 依赖；`AppState` 不再保存移动端服务句柄、Git 自动提交线程、状态缓存与失败记录。

- 前端：扩展页只保留「事项模板 / 脚本钩子」；移除相关 IPC、类型、事件监听与 UI。
- 文档：README 功能全景同步更新。

## 七、用户侧提示

- **外部修改冲突**：数据文件被外部工具修改后，应用会弹「重新加载 / 覆盖」选择，不再静默覆盖。
- **脚本钩子**：默认关闭；启用后执行 `hooks/*.js`（受限解释器，单个脚本限时 2 秒），仅放信任脚本。
- **编辑抽屉**：修改后需点底部「保存」才生效；✕ / 取消会丢弃未保存改动（有改动时二次确认）。
