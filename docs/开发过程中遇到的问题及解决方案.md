# 开发过程中遇到的问题及解决方案

## exe 被锁定
构建最终报 拒绝访问 (os error 5)，原因是上次启动的 schedule-app.exe（PID 6000）仍在后台运行（托盘常驻）。已结束该进程后重试成功。

## 打包工具下载超时
tauri build 首次要从 GitHub 下载 NSIS/WiX 工具集，本机网络较慢触发了 Tauri 内部下载超时（timeout: global）。已手动下载并缓存到 %LOCALAPPDATA%\tauri\（NSIS\ + nsis_tauri_utils.dll v0.5.3、WixTools314\），此后打包不再联网下载。

## MSI 中文产品名冲突
中文产品名「个人日程管理」无法用 WiX 3.x 默认代码页 1252 编码（LGHT0311）。已在 src-tauri/tauri.conf.json 增加 bundle.windows.wix.language = "zh-CN"（代码页 936）解决。
