# 品牌与应用名方案（v1.0.0 正式发布版）

> 产品：个人日程管理桌面应用（Tauri 2 + React，本地优先）
> 核心价值：**回答「此刻该做什么」** —— 事件 / 日常 / 浮动事项 + 五层候选推荐引擎 + 今日时间轴 + 系统级提醒
> 本方案为 1.0.0 正式发布配套的品牌设计：应用名、口号、色板、图标规范与发布应用清单。

---

## 一、应用名方案

### 主推：中文「此刻」 · 英文「MOMENT」

| 项 | 内容 |
| --- | --- |
| 中文名 | **此刻** |
| 英文名 | **MOMENT** |
| 口号 | **此刻，该做什么，一目了然** |
| 英文口号 | *Right now, the right thing.* |

**为什么是「此刻」**

1. **直指产品灵魂**：应用首页名为「现在」，核心能力就是回答「此刻该做什么」。「此刻」把这个答案写进了名字——用户每次打开应用，就是回到「此刻」。
2. **现代简约的命名气质**：双字词、易读易记、零解释成本，符合 2020s 产品命名趋势（潮汐、幕布、滴答、飞书同类的短词路线）。
3. **天然的品牌故事**：时钟 + 琥珀色「此刻」点 = 「在时间的圆环上，标注此刻」。图标与名字互文，推广物料无需额外解释。
4. **英文名 MOMENT**：与「此刻」互译、音节短、字形现代，国际化发布（应用商店、官网、英文版界面）无需改名。

**备选（供决策）**

| 候选 | 英文 | 含义与卖点 | 顾虑 |
| --- | --- | --- | --- |
| 日迹 | RIJI | 谐音「日记」：每一天都有迹可循（归档/统计功能呼应） | 易被听成「日记」，品类联想偏记录而非规划 |
| 时计 | TOKEI | 意为「时钟/计时器」，呼应大时钟首页 | 「TOKEI」是日语读音，中文品牌用易产生定位困惑 |
| 恰时 | ONTIME | 「恰好的时间做恰好的事」 | ONTIME 撞名公交类应用，记忆点不足 |

> 结论：推荐直接采用「**此刻 · MOMENT**」。若后续注册商标冲突，备选优先级为 日迹 RIJI > 恰时 ONTIME > 时计 TOKEI。

## 三、图标规范（1024 基准）

**概念**：时间的圆环（白色时钟 10:10）+ 中心的琥珀点 = **「此刻」**。

| 元素 | 参数 |
| --- | --- |
| 画布 / 外形 | 1024×1024，圆角方形（squircle），圆角 230（≈22.5%，对齐 iOS 图标语言） |
| 背景 | 垂直渐变 `#5C6CFF → #3534B8` |
| 圆环 | 中心 (512,512)，半径 352，线宽 44，白色 |
| 时针 | 10 点方向，长 168，宽 48，圆头，白色 |
| 分针 | 2 点方向（10:10），长 258，宽 36，圆头，白色 |
| 此刻点 | 中心半径 40，`#FFC53D`，位于指针之上 |

**寓意**：10:10 是钟表行业经典「微笑」角度，传达积极、向上的产品情绪；琥珀点把抽象时间锚定在「此刻」，是全图标唯一的暖色记忆点，缩放到 16px 仍可辨识。

**资产来源**：`.tools/render_brand_assets.py` 是单一几何常量源，同时生成 SVG 母版与 PNG 位图，保证矢量与位图零偏差；发布图标集由 `tauri icon` 从 1024 PNG 派生。
