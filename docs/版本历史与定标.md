# 个人日程管理 · 版本历史与定标

> 生效时间：**v1.0.0 正式版**（2026-08-15）。
> 本文档是项目应用版本号的唯一权威定标依据。此前版本号（0.x / 0.3.1 / 侧栏 V3.1 等）仅作为历史记录保留。

---

## 一、定标原则

1. **当前版本 = 1.0.0（正式版）**：功能稳定、核心场景完整，作为首个正式发布版本。
2. **1.0.0 之前按更新内容程度定标**：
   - `0.1.0`：MVP 初始骨架（第一个可运行版本）；
   - 每个功能里程碑 `minor` 位 +1（功能新增/大范围增强）；
   - 缺陷修复与工程治理不单独占位，并入对应里程碑；
   - **V3.1 是面向正式版的稳定性迭代**，功能冻结、集中修缺陷与治理，因此定标为 **1.0.0-rc.1（发布候选）**。
3. **正式版之后**：缺陷修复走 `patch` 位（1.0.1、1.0.2…），新增功能走 `minor` 位（1.1.0、1.2.0…），破坏性变更走 `major` 位（2.0.0…）。
4. **应用版本 ≠ 数据版本**：数据文件的 `version` / `CURRENT_VERSION` 只描述 JSON 存储结构的迁移链（当前为 4），与安装包/界面显示的应用版本相互独立。本次定标**不改变任何数据迁移逻辑**。

## 三、历史版本号与历史构建包名的关系

历史构建包文件名中出现的版本号（例如 V3.0 产物 `个人日程管理_0.1.0_*`、V3.1 产物 `个人日程管理_0.3.1_*`）是当时未统一管理导致的漂移，**仅作为历史构建产物名保留**。本表以「应用版本」列为准，新构建自 1.0.0 起统一使用规范版本号。
