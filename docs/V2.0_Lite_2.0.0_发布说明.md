# 此刻 MOMENT 2.0.0 发布说明

更新日期：2026-10-24。本文件说明2.0.0的交付范围；最终验收状态、确切构建来源、文件哈希和证据日期以产物目录的`manifest.json`为准。`formalRelease:true`只会在完整性、安装器、运行和稳定性门槛通过后生成。

## 版本和安装

- 应用版本`2.0.0`，Android versionCode `200000099`，MSI ProductVersion `2.0.99`；数据格式v6、同步协调协议v2。
- 安装包位于项目D盘目录`.build-cache/releases/2.0.0/`。Android使用`MOMENT-2.0.0-arm64-release.apk`，Windows使用`MOMENT-2.0.0-windows.msi`；逐文件核对`SHA256SUMS.txt`。
- 完整验证范围为Windows10桌面、Android14 HONOR70真机和Android15/16模拟器。Windows11未实测；Android8为实验兼容，仅完成安装、原生启动和旧/缺少浏览组件的引导验证，不能表述为完整支持已验收。其他未测试系统组合也不作已验证声明。
- Android沿用已备份的项目证书，SHA-256为`aef96e480b4ec12fe56b716167a2d154139561f03579fa7c96f7fb0fca12028d`。Windows尚无Authenticode签名，可能显示未知发布者。

手机原应用使用Debug测试证书；正式证书不能直接覆盖安装。当前保留2.0.0 Debug和原业务数据。若要转用正式证书，先在设置导出加密备份，并确认可恢复，再安排卸载和正式包安装；不要为解决签名不一致直接清除数据。本轮测试没有卸载手机原应用。独立的`com.personal.schedule.qa`只保存人工QA数据。

## 本轮完成的功能

七牛同步采用加密快照和不可覆盖协调记录，实现单设备编辑授权、过期接管、基础版本校验、删除传播、冲突副本、上传下载取消和有界重试。所有业务写入口检查编辑权；未配置同步时保持纯本地使用。下载与批量修改使用可恢复事务，保留本地恢复点；设置支持系统文档选择器导入导出和独立口令加密备份。

Windows窗口关闭、托盘退出和Android设置中的“同步并退出”共用交接流程。该操作先暂停本机计时草稿，再上传已保存修改、释放编辑租约并退出。同步失败时可返回应用重试，也可明确选择保留本地退出；后一种情况保留待上传内容，另一设备须等租约到期后再接管。按Home回到桌面不会立即交出编辑权。

退出上传结束后，还会在业务存储锁内重新核对实际内容并冻结写入口；若期间出现新编辑，则保留租约与待上传数据，要求返回应用重试。不能仅凭先前的“已同步”状态提前交还编辑权。

正常退出前，暂停后的计时草稿由原生层写入、同步到磁盘并原子替换，启动时结合较新的本机检查点恢复。关闭期间不累加时长，计时草稿不跨设备同步。异常强制结束仍只能恢复此前成功持久化的检查点，不能承诺结束前最后一毫秒都已保存。已结束的有效会话使用幂等ID，避免重复归档。

同时修复空返回IPC误判取消、删除后不刷新、外部修改基线丢失、并发确认队列、未提交长期任务编辑被会话操作覆盖、自然语言输入边界和损坏配置恢复等问题。Android增加小屏导航、键盘安全区域、浏览组件预检以及原生持久化提醒。

## 使用边界与恢复

Android提醒预排未来48小时、最多128条；打开应用会刷新，系统重启并解锁后恢复已排提醒。系统省电、厂商后台限制或通知/精确定时权限可能影响送达；系统“强行停止”后需重新打开。已完成模拟器Doze/重启和真机后台验证，不承诺所有厂商多日锁屏下持续送达。后台同步在恢复前台时补做。

APK原生库已做16KiB对齐结构检查，尚无16KiB页大小设备的运行证据。存储故障通过确定性失败与事务恢复验证，没有实际填满手机存储。真实30分钟租约到期证据属于前序协议验收，当前相关回归继续运行；准确日期见清单。

升级前保留本地备份。同步口令与证书备份密码由维护者保管，遗失后不能恢复解密。旧协议客户端不能写入v2前缀；回退前断开同步、导出备份，保留原目录并在独立目录恢复，避免直接让旧程序写入新协议空间。

用户于2026-10-24决定自动验收通过后先定版，三天日常试用改为发布后验证；Windows11实测移出本轮门槛，Android8按实验兼容发布。发布后继续观察跨端接续、日常提醒、厂商后台与异常恢复；发现P0/P1时修复并重跑相关验收。

所有项目构建输出、缓存、临时文件、模拟器和安装包保存在D盘。私钥、口令、真实业务数据与测试证据不提交源码仓库，也不随安装包分发。
